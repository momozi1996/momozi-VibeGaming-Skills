# 伊莫 · 风栖原野 — 风格复刻 / 独立单人原型

## 参考与范围
2026-09-18 联网获取 Steam app 4126040 的14张原始官方截图、详情 JSON 与 aniimo.com 官网 HTML。主参考 steam-00（草原捕捉），辅助 steam-09（探索 HUD）、steam-02（图鉴）。只作本地研究，不将截图当作场景或贴图，不使用官方角色3D资产。

依照 allgame 的 adventure/exploration+collectathon 工艺：单一状态、统一 heightAt、第三人称相机、实例化植被、输入释放、目标提交、保存重开和截图验收。已观察其 courtyard golden，保留远中近层次/可达路/角色阴影；不继承中世纪骑士、建筑、美术及战斗任务。不直接复制基线工程，独立 Three.js 实现以适配本次萌宠与草甸 shader。

## 新增
- 原创程序化草原、河湾、风之门、浮空都市远景、圆润树木、草与白色花海。
- 原创粉帽蓝背包探险家与4类可捕捉生物：绵云、焰尾、泡泡、芽芽；名字和简化造型不声称等同原版。
- WASD、Shift、Space、拖拽相机、滚轮缩放；E/鼠标捕捉；Q合体与伙伴能力；1—4选择伙伴。
- 捕捉3种→前往风之门→E提交→一次性奖励→继续探索/重开。
- 地图、图鉴、暂停、摄影PNG、音效、质量、独立版本存档。
- 世界单位米/秒，XZ平面。统一高度函数供地形、宠物、移动、地图使用。

## 非目标
完整原版1:1美术/动作、真实多人、服务器/账号/交易、完整MMO内容、官方城市场景内部、商业发行授权。移动端只提供适配和基础触控，不承诺真机性能。

## 验收
真输入移动/相机/跳跃；近距捕捉成功和远距拒绝；不重复收集；3种才解锁风之门；奖励一次；暂停时间冻结；刷新恢复；重开与坏档容错；图鉴/小地图状态一致；生产无测试传送接口；浏览器无异常并实际查看画面。
