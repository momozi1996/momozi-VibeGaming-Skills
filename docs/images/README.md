## 处理方式

- 原图在 `skills/` 中保持原样；所有正式 ZIP 与其 SHA-256 不变。
- JPEG 展示副本等比例缩到最长边不超过 1280 px，不裁切、不拉伸、不调色、不合成游戏内容。格斗图为原尺寸 1280×800 PNG，保持像素细节。
- 首页不用表格嵌图，也不用 HTML 图片标签；路径为英文相对路径，避免中文路径转义与不同 Markdown 渲染器的布局差异。
- 副本去掉元数据；总大小约 3.51 MiB，随 docs 进入发行清单，不依赖外部图床。
- 这些是原有基线的展示副本，不是 2026-09-21 新一轮完整玩法验收。素材权利边界仍见 [RIGHTS](../RIGHTS.md)。
