## 冻结和公开发布的区别

当前Git索引跟踪 **51,857路径**，其中48,107属于node_modules、50,316位于verification，二者有重叠。`.gitignore`不能清掉已经跟踪的文件或旧提交；当前无公开远端，未进行Git暂存、提交、tag、历史清理或LFS上传。

**对外前仍须处理：**

- 自有源码、美术、skill/仓库工具的明确授权；没有统一许可时不标“全仓MIT”。
- Riot专有图片/数据、商业游戏研究图、品牌与设定的再分发权；需要替换时建立新公开基线，不能边改文件边沿用旧哈希。
- 四份源记录的用户/临时/上游构建路径，以及其他历史证据的公开适宜性；清单见RIGHTS。
- 三份>100MiB文件的LFS实体或Release分发方案；配置.gitattributes不等于已经上传。
- 在干净仓库完成真实远端CI和下载验证。

可先保留本地冻结候选。用于交付的干净目录应从已审核清单导出，不使用Finder整目录复制，也不以当前Git索引作为发行文件集：

```bash
python3 scripts/audit_packages.py --check-lock
python3 scripts/export_release.py --out ../game-skill-packages-2026.09.21-rc4
cd ../game-skill-packages-2026.09.21-rc4
python3 scripts/audit_packages.py --check-lock
```

导出不会脱敏、替换版权素材或授予许可，也不会自动上传。发行目录不含.git、verification、playable-games或node_modules。
