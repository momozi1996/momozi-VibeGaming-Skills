# 大框架与取舍

## 目标

一个完成度可验收的 **北郡修道院外景 vertical slice（纵向切片）**。将资源投入一个区域、一种职业、一条闭环任务，不伪装成完整 MMORPG。

### 美术方向

- 参考已存档的北郡修道院实机画面：浅色砌石、红陶瓦、非对称多翼建筑、尖拱和彩窗。
- 不直接移植原作网格/贴图。外景建筑以细分构件建模并按材质合并；不使用“纯色方块房子”兜底。
- 模型使用 GLB；人物包含骨骼和动作。外景采用贴图、法线、透明叶片、阴影、环境光遮蔽；角色使用 glTF PBR 材质。
- 世界比例、场景布置、卫兵名称与任务均为演示重新设计，不能用作原作地图资料。

## 子系统边界

| 层 | 责任 | 不承担 |
|---|---|---|
| `main` | DOM入口、顶层错误提示 | 地图、技能、UI状态 |
| `Game` | 初始化顺序、循环、系统连接、交互路由 | 材质细节、角色网格、窗口布局 |
| `world` | 地形采样、构件建造、植被、道具、批次 | 任务存档、UI |
| `actors` | 模型实例、动作切换、运动与碰撞 | 奖励规则 |
| `Combat` | 选敌、技能冷却/资源、敌人状态 | HTML布局、文件下载 |
| `GameState` | 可保存进度与运行时状态、受伤/升级/任务计数 | 3D渲染 |
| `UI` / `Minimap` | 中文HUD、窗口、地图、输入反馈 | 直接修改敌人生命 |
| `Audio` / `Effects` | 有限生命周期的呈现 | 决定战斗结果 |

- 世界以水平 XZ 坐标布置，Y 使用同一 `heightAt(x,z)` 采样。
- 角色移动与渲染地形使用相同高度函数；GPU顶点缓冲明确可更新。
- 镜头跟随使用保持 alpha/beta/radius 的 `ArcRotateCamera.setTarget`，不重新计算跟随半径。
- 相同材质的静态建筑/道具合并；重复树与草使用 thin instances；不为每一片草创建独立交互对象。
- 碰撞为静态建筑矩形与树干圆形阻挡，并非完整刚体物理/导航网格。

## 状态与流程

任务状态：

```text
available --守卫处接受--> active --3只狼 + 2束花--> return --守卫处领奖--> complete
```

- 目标进度只在任务活动时累加；达标后可交付；已完成任务不重复领奖。
- 普通攻击按钮为开关命令；挥砍冷却控制命中节奏，而不是拒绝新的开关命令。
- 技能由表驱动：名称、图标、按键、怒气、冷却；效果由战斗模块处理。
- 游戏时间在暂停、窗口打开、页面后台或摄影模式时停止；同步暂停骨骼动画。
- 摄影模式单独保留环绕与缩放，截图只导出世界画面。
- 死亡不删除任务；返回庭院，恢复生命并重置敌人。

存档只保存可验证的领域数据，不保存 Babylon 对象。解析时校验版本、有限数值、范围与任务阶段。存储失败返回失败状态，不崩溃。重置前关闭自动存档写入，避免 `beforeunload` 写回刚删除的存档。

## 资源流程

```text
官方/作者页面核验CC0
 → 真正下载ZIP/HDR/MP3，检验容器或哈希
 → 选择与风格统一、适合网页体积的部分
 → 原创重建与再贴图
 → public/assets 本地资源
 → 来源/授权证据/字节数/SHA-256 清单
 → 浏览器不依赖外部素材站
```

全站“免费”不是授权证据。没有下载成功、授权不明或不符合 CC0 的候选不进入游戏。

## 当前不包含

- 联机、账号、服务器权威战斗、完整开放世界。
- 修道院室内、地牢、专业、交易经济、多职业和角色创建。
- 原版任务复刻、原版地形/建筑比例复刻、原版UI或音乐。
- AAA角色拓扑、表情、布料模拟、运动匹配、动态天气和昼夜系统。
- Safari / Firefox / 手机的正式兼容性验收。

下一阶段应优先精修原作地标比例和高质量角色动作，而不是先堆更多区域与系统。
