# 伊莫 · 风栖原野

基于用户提供的 [Steam 页面](https://store.steampowered.com/app/4126040/_/)和官方截图制作的 **非官方、单人、3D 浏览器风格原型**。不是原版客户端或完整 MMO，也没有接入多人服务。

## 先看参考

- `references/index.html`：14 张官方截图的可浏览参考册、配色与美术分析。
- `references/contact-sheet.jpg`：官方截图总览。
- `references/sources.json`：实际下载的来源 URL、字节数、SHA-256。
- `references/steam-appdetails.json` / `official-site.html`：2026-09-18 联网获取的页面资料。

主要参考：草原捉宠 `steam-00.jpg`、探索HUD `steam-09.jpg`、伊莫图鉴 `steam-02.jpg`。官方截图只作研究，不被加载进游戏，不进入 `dist`。

## 启动

Node.js 20+，支持 WebGL2 的 Chrome / Edge / Safari。

```bash
cd aniimo-world
npm ci
npm run dev -- --port 4318 --strictPort
# http://127.0.0.1:4318
# 参考册：http://127.0.0.1:4318/references/index.html
```

生产版：

```bash
npm run build
npm run preview -- --port 4327 --strictPort
# http://127.0.0.1:4327
```

使用 HTTP 服务运行，不要直接双击 `index.html`。成品构建和游戏画面不依赖外部图片、字体、模型或在线服务。

触屏界面提供左侧摇杆、拖拽环视和右侧动作按钮。已做 Chrome 模拟触屏测试，未做物理手机性能验收。

### 第一段旅途

1. 沿小径前行，靠近白色绵云，按 E 投出联结球。
2. 寻找另外两种生物，结识 **三种不同的伊莫**。同种不同个体不重复计入种类目标。
3. 抵达风之门，7米内按 E，完成探索委托，获得一次性的 300 星屑和 10 联结球。
4. 可以继续寻找全部四种，或在暂停设置里确认重新开始。

合体能力：绵云/芽芽二段跳，焰尾更快奔跑，泡泡水面通行不减速。捕捉采用近距1.5秒必成功的原型规则，没有复刻原版概率/属性战斗系统。

进度保存在本浏览器 `localStorage` 的独立键 `windmeadow-aniimo-prototype-v1`。无账号、无云存档，浏览器清理站点数据会丢失进度。

## 实现

- Three.js 0.180 + Vite；约160k动态风草实例、实例化花海与植被、合批几何、程序化云、水、地形和原创简化角色。
- 独立逻辑 `src/state.js`；统一地面函数 `src/terrain.js`；场景、模型、输入、UI、声音分别分层。
- 同一份地图和地形数据驱动场景、移动、野生伊莫、任务和小地图。
- 游戏运行美术由源码生成。不是截图铺底，也没有嵌入原游戏视频。

## 验证

```bash
npm test                        # 11 项逻辑测试
npm run build
npm run test:browser             # 启动4318开发服务后，25项浏览器检查
node tests/production.mjs        # 启动4327生产预览后，生产+模拟触屏检查
```

测试默认使用 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，其他系统通过 `CHROME_PATH` 指定浏览器可执行路径。`TEST_URL` / `PROD_URL` 可覆盖端口。

报告和截图在 `reports/`。开发浏览器测试中的第2、第3只伊莫及风之门使用 **DEV传送夹具**缩短路线；首次走动/捕捉、全部捕捉按键、跳跃、地图、图鉴、结算、存档和导出均实际触发。生产包无 `__ANIIMO__` 测试入口。

## 已知差异

- 场景、人物与四种生物是原创简化造型，不是原版模型、骨骼或动画，不能视为美术1:1复刻。
- 只实现小型开放探索区域；浮空都市是远景地标，不能进入。
- 没有联网、战斗、交易、家园建造、城市场景或原版完整剧情。
- 生物活动和物理为轻量实现；相机可穿过部分植被，陡坡和河流没有完整物理求解。
- 星屑是已完成委托的奖励记录，未实现商店消费；体力/生命条为固定满值，当前和平探索没有伤害或消耗。
- 设置中的音效为合成提示音，默认关闭，无背景音乐。
- 画面质量和帧率受设备影响，未做长时间压力测试或物理手机测试。
