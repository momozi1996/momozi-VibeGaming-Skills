## 已实测
真实键盘移动、远距拒捕/近距捕捉、背包同步、Q切换联结形态、绵云二段跳、选伙伴、暂停冻结、鼠标视角、地图、图鉴、三种目标、风之门一次奖励、刷新恢复、摄影PNG、确认重开和持久化、blur释放输入、生产调试接口剥离、触控摇杆与释放、移动地图窗口和不遮挡。

## 画面检查与修正
实际打开并观察开发场景、图鉴、联结、生产场景、手机竖屏与地图截图。首轮发现草过高、路过宽、相机看地过多、背景云过于几何化，调整了草形/密度、相机目标、云shader、树冠表面/实例叶片、山地。后续发现手机模态窗口被摇杆遮挡，已修复并增加专门断言。

## 环境与性能
macOS Google Chrome / ANGLE Metal；桌面1440×900 DPR1、触屏模拟390×844。开发报告末次短采样真实rAF约 53.8 FPS、141 draw calls、1,589,542 triangles；这不是长期性能保证，不代表所有设备。

未验证：物理手机、多人、长期内存压力、完整场景可达性人工巡检和听感；原型没有真实MMO服务、原版战斗、完整资产与城市场景内部。
