# survivorGame · 月灯生存创作工坊

把需求做成**能打开、能操作、能完成目标并重开的游戏**。本 skill 是独立完整包：原生 Canvas/ES modules 工程、原创 SVG 美术与生成源稿、两套主题、游戏系统和创作经验都在本目录。不依赖另外三个 game skill、原始 note、联网素材、模型 API 或 npm。

`SKILL` 是本文件所在目录。需要能读写文件、运行 Python 3 和打开现代浏览器的 code agent；不支持技能发现的 agent 直接读本文件。安装一次后，常规创作无需再次安装其他包。离线起点可直接运行；不承诺任意模型一次完成任意新游戏，也不把配色更换说成全新美术。

## 先交付可玩的起点，再完成用户创作

1. 根据用户目标查看 `assets/preview.jpg` 与 [玩法/实现地图](references/gameplay.md)。原样试玩就直接生成；有新主题就记录输出项目 `CREATIVE-BRIEF.md` 中继承项与本轮要改的角色、场景、玩法和 UI。
2. 将完整工程生成到**安装目录之外的新目录**。不要在技能内开发或覆盖已有项目。已有游戏则增量改造，不重复 create。

```bash
python3 "<SKILL>/scripts/game.py" themes
python3 "<SKILL>/scripts/game.py" create --theme moon --out "<NEW_PROJECT>"
# 第二套主题：--theme ember；可加 --title "我的新游戏"
python3 "<NEW_PROJECT>/start.py" --port 4310
# 打开 http://127.0.0.1:4310
```

这里没有 npm install 步骤：运行代码、字体、图形和音效均本地可得。不要双击 index.html，ES modules/config 需要 HTTP。占用端口就另选，不关闭用户其他服务。

3. 明确的用户改造需求必须继续实现，不能止于 create。按 [创作配方](references/remix.md) 和 [美术工艺](references/art-direction.md) 改 角色 SVG、法术轨迹、敌人轮廓/行为、竞技场地形、升级组合和首领技能。生成工具只选内置主题/标题，不自动兑现任意创意。
4. 给用户可试玩地址、项目位置和控制方式。实际开局做一次当前改动涉及的主要交互，检查无白屏/缺资源；美感与最终体验交给用户人工试玩。没有浏览器就明确未打开，不编造试玩结果。无需单独的测试调试 skill，也不把全面测试套件作为每次创作的前置门槛。

## 保住这款游戏的辨识度与完整性

- 闭环：移动躲避 → 自动攻击 → 收集星砂 → 三选一升级 → 星环/冲刺 → 首领出现 → 胜负结算与重开。
- 美术：月蓝森林、暖金星灯、青绿魔法；头戴星帽的小女巫、飞蛾、石像与软泥怪。前景植物、发光灯柱、漂浮粒子、分层群山形成深度。
- 不能退化为占位方块、普通网页后台或静态截图。场景有层次，角色有完整轮廓，关键交互有动画/音效/状态反馈。
- 只在当前项目改实现；内置工程是可恢复起点。`--title` 不会替换角色和场景；真正换风格要改造形体、布局、配色和反馈。
- 保持输入→玩法状态→表现的单向关系；暂停停止玩法时间，绘制可继续环境动画。
- 按需读当前模块，不一次加载全部源文件。单 agent 可完成，不要求多 agent、Blender 或 AI 生图。用户自有/新生成素材可选接入，但普通运行不调用外部服务。
