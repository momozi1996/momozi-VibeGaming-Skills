# 风物小园

启动：`python3 start.py --port 4310`，打开 http://127.0.0.1:4310 。不需要 npm，不要双击 HTML。

播种 → 浇水 → 生长 → 收获 → 售卖 / 交付订单 → 修缮 → 三份心愿完成 → 存档后继续花园。

配置位于 game-config.json；实现位于 src/game.js；美术是 public/art 下的本地 SVG。修改后刷新。全套素材生产源稿在 tools/draw_art.py，执行会覆盖同名 SVG，请先保存手动修改。

24 块田、3 类作物、3 份订单和 2 次修缮的轻经营游戏；不是完整牧场物语或多人社区。
