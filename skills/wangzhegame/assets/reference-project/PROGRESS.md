## 2026-09-21 · v0.1.1 操作修复（当前版本）

### 复现 / 根因
- 旧版在真实浏览器按 ArrowUp/W/A/S 后英雄坐标完全不变；D 触发的是闪现；左键地面没有移动处理。记录：`artifacts/controls/before-fix.json`。
- 输入只有右键点选寻路；W/D 与常见 WASD 移动预期冲突；方向键只用于自由镜头。
- 右键拖动原来只在 pointermove 节流时重算，快速拖到最后位置可能仍追踪中间位置；现在按住右键时持续采样最终鼠标位置。

### 修复
- `src/controls.js` 单独管理输入。默认 WASD + 箭头移动，1–4 技能，F/G 闪现/治疗；C 和原生按钮切换经典 QWER/D/F，箭头始终移动。
- 模拟 `steer` 使用归一化方向矢量，每固定步按真实 speed 移动；不依赖 key repeat。沿用碰撞/边界，斜向不加速、松键即停，键盘覆盖旧的点击追击/路径。
- 左键和右键均可走位/攻击；鼠标右键按住持续更新目的地。镜头仍可中键拖动、滚轮缩放，Alt+方向键在自由镜头下平移。
- 原生技能图标：自身技能直接施放，指向技能先点击图标再左键目标；闪现同理。右键/Esc 取消瞄准。
- UI 热键提示与操作方案同步；新增显式商店、回城按钮。右键普通 UI 不触发购买/重开，底部 HUD/帮助/战绩阻断点穿。
- 暂停、商店、TAB、失焦和方案切换释放按键；暂停时 P 不再在后面打开隐形商店。
- 当前 UI 仍为单一 WebGL canvas，无 HTML 控件。
