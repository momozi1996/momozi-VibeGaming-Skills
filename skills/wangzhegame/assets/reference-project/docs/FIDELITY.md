# 精确度 / 差异账本

“已实现”是功能事实；“有来源”是数据事实；二者均不自动等于与 LOL 一致。

## 可核验的数据与实现

| 项目 | 依据 | 当前实现 / 限制 |
|---|---|---|
| 版本 | Data Dragon versions.json | 锁定 16.18.1，不运行时追随 latest |
| 基础生命、法力、护甲、魔抗、移速、普攻距离与速度 | 每英雄原始 JSON 的 stats | 1 级初始化直接使用；以单测验证相等 |
| 每级成长 | stats + `0.7025(n−1)+0.0175(n−1)²` | 成长函数被测试；多个英雄 `attackdamageperlevel` 为 0，沿用源字段，但未获另一官方数据源确认，不声称这等于实际服务器成长 |
| 技能 rank 1 消耗 / 冷却 | spells[].cost/cooldown | 直接读取；不含全部充能、重置、装备减 CD、可变冷却等机制 |
| 移动 | 同一游戏坐标 / 秒 | 无增益盖伦每秒 340 单位被验证；渲染尺度不是现实尺度 |
| 护甲减伤 | 正负抗性公式 | 被单测验证，未实现所有穿透和修正顺序 |
| 出兵 | 项目锁定标准节奏 | 01:05，之后每 30 秒；训练显式改为 00:05 |
| 闪现距离 | 固定规则 400 单位 | 距离与冷却被验证；穿墙规则简化为目标可行走检查 |

## 明确的重建 / 简化

- **地图**：15000 方形域、三路和对角河道是自建拓扑。塔、野怪、碰撞圈的位置是本项目坐标，不是官方 Summoner's Rift 网格。
- **真实尺寸**：没有原版网格、角色骨架或碰撞导出，因此无法声称视觉比例和碰撞体精确。世界坐标可测量，不等于真实地图已对齐。
- **美术**：程序化角色/建筑、纹理地面、植被卡片、程序动作。不是官方角色模型、动作、PBR/手绘材质或完整光照风格，画质尚未达到原作。
- **技能公式**：大部分 Data Dragon `effect` 为 0 / 占位。代码内伤害系数是明确的重建数值，未经官方技能脚本校验。范围和方向效果存在，并非服务器等价实现。
- **英雄细节**：盖伦 W 层数/E 暴击、艾希完整 Q 专注衰减与 E 充能、安妮完整被动规则、拉克丝被动/护盾往返、易完整不可选取/双重打击和击杀重置等未完整还原。拉克丝 W 为范围即时护盾，E 为 3 秒自动爆炸。
- **技能升级**：2/3/6 级自动解锁 W/E/R，只有 rank 1 主动数据；没有技能点分配和满级成长。
- **伤害**：没有完整攻击前摇/弹道取消、技能急速、暴击/穿透/吸血/韧性/控制分类、视野边缘、AI 预测。当前禁锢和眩晕共用停止行为状态。
- **单位体积**：圆形半径用于射程和命中；没有完整单位避让/推挤。英雄移动有障碍网格寻路，其他 AI 路径/避障较简化。
- **防御塔**：22 塔、链式保护、兵线优先与攻击英雄转仇恨已做；统一生命/伤害值，没有镀层、时间成长、仇恨递增等全规则。建筑几何并非全部纳入导航碰撞。
- **经济/经验**：局部补刀、击杀、助攻、经验、复活、自动金币已做；金币从对局起始增长，未对齐官方被动金币启用时点；经验分享、赏金、连杀、传送等未完整实现。
- **装备**：9 个条目；基础条目手工设定，两个高级条目标为“演武”，药水为即时治疗；无合成树、出售、撤销或主动装备。不是官方完整商店。
- **野区**：8 个固定营地，怪物造型/生命/掉落/刷新是项目规则；“巨龙/峡谷巨兽”不等于原版完整龙魂、地形、男爵 buff 系统；部分获得的 buff 仅记录，不完整影响全部属性。
- **地图机制**：没有战争迷雾、草丛隐藏、守卫、视野阻挡、真实侦察；因此艾希 E 仅保留侦察表现/状态，当前没有新增可揭示的信息。
- **召唤师技能**：D 闪现 / F 治疗；治疗仅作用自身，其余召唤师技能未做。
- **对局系统**：单机人机，无账号、匹配、联网、回放、排位、反作弊、符文、皮肤和全部设置。

## 验收状态

本工程可以验证 MOBA 对局闭环与引擎内 UI 技术路径。**用户要求的“同一张图、画质对得上、LOL 有什么它就有什么、真实尺寸和全部机制精确实现”尚未完成，不能以本工程冒充已达标交付。**

进一步精确重建需要：合法可用的原版/等价高质量资产、地图空间/碰撞参考、固定版本的完整规则规范、逐英雄测试集、足够的资产制作与调参周期。
