# RIFT FORGE · 峡谷演武

**本地、单人、5v5 人机 MOBA 技术验证工程。不是《英雄联盟》的完整复刻，也尚未达到用户要求的原版地图、完整机制和画质。**

## 运行

需要 Node.js 20.19+，推荐桌面 Chrome / Edge 和支持 WebGL2 的 GPU。

```sh
npm ci
npm run dev
# http://127.0.0.1:4411
```

当前生产构建也可以直接静态托管，不需要下载运行美术：

```sh
python3 -m http.server 4412 --directory dist
# http://127.0.0.1:4412
```

macOS 可双击 `启动游戏.command`，通过 Python 静态服务打开 `dist`。不需全局安装依赖。不支持直接双击 index.html 的 file:// 访问。

## 现有功能

- 五位英雄：盖伦、艾希、安妮、拉克丝、易；双方各五位英雄，玩家控制一位，其余九位由本地 AI 控制。
- 一张程序化三路地图：河道、野区、22 座防御塔、6 座召唤水晶、2 座枢纽；三路兵线、近战/远程/炮车/超级兵。
- 5 位英雄的 QWER 功能分支，投射物、近战、范围伤害、减速、禁锢、护盾、提伯斯召唤、闪现、治疗、回城。
- 生命/法力、等级成长、经验、补刀与击杀金币、助攻、装备购买、死亡复活、AI 推进、胜负和重开。
- **一个 WebGL canvas**。选人界面、HUD、血条、小地图、商店、暂停、战绩、结算均为正交 UI scene 中的纹理图层。没有 HTML HUD、按钮或网页面板。
- 菜单插画/头像/技能图标来自 Riot Data Dragon；世界不是背景图片，战场、单位、建筑实时 3D 渲染。

## 两种开局

| 开局 | 等级 / 金币 | 第一波兵线 | 后续兵线 |
|---|---|---|---|
| 标准节奏（默认） | 1 / 500 | 01:05 | 每 30 秒 |
| 训练开局 | 6 / 1500 | 00:05 | 每 30 秒 |

“标准节奏”只描述开局与出兵节奏，不等于完整标准 LOL 规则。Q 默认可用，W / E 在 2 / 3 级自动解锁，R 在 6 级自动解锁；没有手动技能加点、完整符文或天赋。

## 操作（已修复键盘移动）

**默认 WASD 操作；方向键在两种模式都控制角色，不再单独控制镜头。**

| 输入 | 默认 WASD 模式 | 经典模式（按 C 切换） |
|---|---|---|
| W A S D | 前左后右移动，松键即停 | QWER 技能 / D 闪现 / S 停止 |
| ↑ ↓ ← → | 角色前后左右移动 | 角色前后左右移动 |
| 左键或右键地面 / 敌人 | 移动 / 追击普攻 | 同左 |
| 按住右键拖动 | 持续更新走位目标 | 同左 |
| 1 2 3 4 | 四个技能，朝鼠标方向施放 | Q W E R |
| F / G | 闪现 / 治疗 | D / F |
| C / 右上角操作按钮 | 切换到经典键位 | 切回 WASD |
| X | 停止移动与追击 | X 或 S |
| B / 回城按钮 | 8 秒回城，移动或受伤打断 | 同左 |
| P / 商店按钮 | 打开商店，泉水范围内或死亡时购买 | 同左 |
| Y / 空格 | 切换锁定相机 / 重新跟随 | 同左 |
| 中键拖动 / Alt+方向键 | 自由镜头平移（Alt+方向键需自由镜头） | 同左 |
| 滚轮 | 缩放 | 同左 |
| 小地图左键 / 右键 | 观察位置 / 下达移动命令 | 同左 |
| TAB / 顶部比分 | 按住看战绩 / 点击开关战绩 | 同左 |
| Esc | 取消技能瞄准、关闭弹层或暂停 | 同左 |
| H / M | 操作提示 / 静音 | 同左 |

- 直接点击**自身技能**图标立即施放；点击**指向技能 / 闪现**图标后，再左键选择目标施放，右键或 Esc 取消瞄准。
- 技能栏、召唤师技能栏和屏幕提示随操作方案更新，W/D 不会一边移动一边误放技能。
- 斜向速度归一化；失焦自动暂停并释放按键；商店、战绩和暂停界面拦截角色操作，避免点穿。
- 右键 UI 按钮不触发购买/重开等左键操作。小地图右键仍下达移动命令。
- 当前仅桌面键鼠，不宣称手机可玩。浏览器打开旧标签时需要刷新加载新版本。

## 数据与精确度

先读 [`PLAN.md`](PLAN.md) 和 [`docs/FIDELITY.md`](docs/FIDELITY.md)。

- 固定数据版本：**16.18.1**，原始数据与 SHA-256 来源在 `public/assets/manifest.json`。
- 模拟单位是游戏单位与秒；100 游戏单位映射为 1 个渲染单位，**不是现实米制换算**。
- 英雄初始属性直接读取锁定版本；公开数据的缺失/占位值不等于完整游戏服务端规则。
- 地图域 15000 × 15000 为重建约定，几何、碰撞和程序化模型均非原版。技能公式、部分装备、野怪与 AI 均存在简化。
- 当前画面是程序化风格化 3D，**没有达到 LOL 原版角色、地图、美术资产与动画品质**。

## 验证

```sh
npm test
npm run build
npm run test:browser    # 需要 4411 服务、Chrome
node tests/production.mjs # 需要 4412 生产服务、Chrome
node tests/controls-browser.mjs  # 全面键盘、鼠标与按钮回归，4411
node tests/controls-production.mjs # 实际 dist 的角色移动回归，4412
node tests/soak.mjs
node tests/natural-match.mjs
```

测试和截图位于 `artifacts/`；各报告明确区分真实输入与测试夹具，不把强制胜利的夹具视为自然完整对局。

- 规则测试覆盖基础属性、距离、出兵、伤害、冷却、解锁、购买、20 个技能分支、死亡复活、建筑保护和重开。
- 浏览器测试覆盖真实选人/开始/右键移动/Q/购买/暂停以及夹具战斗/死亡/胜利。
- `dist` 不暴露开发调试 API；开发服的 `window.__RIFT` 仅供自动验收。
- 构建保留 Three.js 的 >500KB chunk 提示，没有通过调高阈值隐藏警告。

## 文件

- `src/config.js`：地图、单位换算、英雄列表、装备、共享障碍和路径。
- `src/simulation.js`：单一对局状态、移动寻路、战斗、经济、AI、结算。
- `src/world.js`：场景、程序模型、材质、动作与特效。
- `src/ui.js`：引擎内界面绘制和命中区域。
- `src/controls.js`：双操作方案、键鼠事件、输入释放与 UI 命中分发。
- `src/main.js`：渲染、固定步进、相机、音效。
