# Aloha Kart / 夏日猫猫大奖赛
Assumption: a playable original browser arcade racer inspired by accessible kart-racing mechanics, not an official Nintendo product or literal production AAA release.
Direction: premium stylized summer animation, creamy sunlit sand, layered turquoise lagoon, lush bent coconut palms, coral/white edge blocks, Hawaiian beach details. Six collectible-looking expressive cats in hand-modeled karts. Menu is a rendered race-world with a front 3/4 hero kart; races use responsive low trailing camera.
Experience: select cat → 3,2,1 → 8-kart 3-lap race → results → retry. Keyboard and touch; drifting, boost pads, coins and items. Sound/music user-toggleable. No login/no runtime asset dependency.
Technical reference checked 2026-09-11: https://threejs.org/docs/pages/WebGLRenderer.html and https://threejs.org/docs/pages/CatmullRomCurve3.html . Reproducible pinned Three.js 0.180.0 / Vite 6.3.5, not a claim to be latest.
