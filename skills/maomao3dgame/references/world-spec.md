# 海岛与赛道参数

## 曲线

完整控制点见 project-spec.json。按原顺序以 y=.24 构建 closed CatmullRomCurve3(points,true,'centripetal',.5)，arcLengthDivisions4096。长约914.3483378108921米，宽16米。不要换成圆或8字赛道。

`sample(u,lateral)` 用 getPointAt/getTangentAt，法线右向；最近点1200段投影；地图160点。所有视觉/AI/拾取/小地图共用这一条曲线。

## 岛屿 / 海面

- 确定性随机种子6202611，LCG：seed=(imul(seed,1664525)+1013904223)>>>0，除以4294967296。
- **调用顺序会改变场景分布**；exact 使用原 track.js，不能在前面随手增加 random()。
- 海岸使用曲线2048采样→256方向半径箱；半径=插值轨道半径+28+sin(angle*5)*2。
- 地面24环×256段，y=-.08；外缘0.89→1下降1.27。中心草色#85b867、沙#f8dba9、湿沙#c8cdac。

- 路肩两组InstancedMesh，方块 .55×.24×2.2，每2.25米一块，cream/coral交替，lateral±8.1。

## 几何正确性 / 性能

plane/带状地面从上方看必须正面可见，computeVertexNormals 不会修复错误绕序。静态物体按材质合并，路肩用实例。不要每棵叶片一个draw call；拾取保持单独可见性。预算以实测为准，开工的<350不适用于整场8车+阴影+后期统计。
