# 已知回归与定位顺序

只修新的输出目录；exact里若只因工具路径问题，不要顺手重构游戏。

| 症状 | 本项目原因/必须保留的处理 | 验证 |
|---|---|---|
| 叶片/草出现黑色或实心方片 | PNG透明度不够，材质还需hasAlpha/useAlphaFromDiffuseTexture、alpha-test与双面光照；见materials.ts | 近看树冠和地面，透明区不遮背景 |
| 树冠或树干不见、薄实例布局异常 | 克隆mesh共享geometry；需makeGeometryUnique后再绑定不同thin-instance缓冲 | 正面与侧面截图都看，不能只统计实例数 |
| 人在坡上漂浮而树正常 | 创建地形没设置updatable，CPU高度写了而GPU没更新 | edge测试检查真实顶点缓冲，别仅检查heightAt数值 |
| 移动时镜头越拉越远 | ArcRotateCamera.setTarget默认重算球坐标 | 保留参数false,true,true；位移前后比较radius |
| 相同种子但树位置不同 | 多插一次random调用、遍历顺序变化或换了随机算法 | 整体布局比对；不能随意增减种子调用 |
| 主角变黑/盔甲颜色改变 | 忘记本地forest.hdr、环境强度、GLTF loader副作用或改变材质色空间 | 看真实角色与肖像，不用增大所有灯亮度掩盖 |
| 手动选新狼后按1没响应 | 普攻开关被全技能通用CD检查拦住 | 开关逻辑先于cooldown检查；完整3狼闭环 |
| 暂停了但人物仍在跑 | 只停止游戏时钟，未暂停scene.animationsEnabled | 摄影前后定时比对骨骼、位置 |
| 摄影不能转镜头 | 把全部paused输入都关掉 | 摄影例外保留onOrbit；拍摄PNG签名和尺寸有效 |
| 开着背包喝药数字不变 | 只更新HUD未重绘模态内容 | 喝药前后查看弹窗数量、生命和冷却 |
| 点过音量条后Esc不工作 | 表单焦点过滤放在Escape处理之前 | 聚焦range后按Esc |
| 删除存档后又出现 | beforeunload把内存状态保存回去 | 重置前禁用state.started/自动保存，确认刷新 |
| 屋顶404但还能开始 | 进度文案覆盖error，ready仍设true | assetError门禁；故障注入必须停止进入，不用纯色替代 |
| E2E通过却不是新的项目 | 默认4173连到了原开发服务 | 用包内wrapper，strictPort，报告记录目标路径和端口 |
| 同机定镜头但AO/阴影仍有随机差分 | SSAO2内核在构造时使用Math.random；capture工具先注入种子20260914，而不是删AO或调低图像阈值 | 两次新浏览器捕获比对；种子只用于测试，不改游戏 |
| 源码一样但图像不同 | DPR、系统字体、GPU、浏览器版本、视角/动画/时间不同 | 先固定capture脚本参数与环境，不先改美术 |
| 构建体积激增 | 换成引擎barrel import触发大量额外模块 | 保持细粒度imports和需要的side-effect注册 |
| 副作用缺失引发拾取/动画错误 | “清理无用import”删掉了ray/碰撞/thin-instance/animatable/glTF注册 | 保留Game开头声明；编译通过不等于运行通过 |

## 处理顺序

1. 当前项目/端口是否正确，素材与版本哈希是否匹配。
2. 复现最小失败，保留控制台、网络、截图与命令。
3. 查对应源模块/冻结测试，修实现，不削弱测试。
4. 重跑失败项，随后完整all套件避免局部修复破坏存档或摄影。
5. 更新差异记录；不要声称修改后仍逐文件完全相同。
