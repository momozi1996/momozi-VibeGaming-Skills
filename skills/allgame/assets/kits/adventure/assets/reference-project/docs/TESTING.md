# 验收记录

测试日期：**2026-09-14**。

## 环境与方式

- macOS，Google Chrome headless，真实 WebGL/Metal 渲染路径。
- 浏览器报告渲染器：`ANGLE (Apple, ANGLE Metal Renderer: Apple M3, Unspecified Version)`。
- 主截图分辨率：1600 × 1000；另验证 1280 × 720 无横向溢出。
- 使用正式浏览器执行并检查截图，不以纯 DOM 存在代替三维场景验证。
- 未禁用浏览器 Web 安全机制；没有从互联网热链模型/贴图。

## 通过项目

### 单元测试：15/15

- 数值限幅、插值、最短角度插值、种子随机可重复。
- 初始存档对象相互独立。
- 无效 JSON、版本、不合法任务阶段与非法数值被拒绝。
- 存档边界、世界坐标、生命值与计数限幅。
- 两个任务目标必须同时达成；完成任务不被重新激活。
- 击杀经验 + 任务奖励的升级与回血。
- 大额经验不会越过等级上限或撑破经验条。
- 伤害、死亡、治疗与自动攻击状态。
- 存档/继续、死亡存档恢复、浏览器拒绝存储、日志长度上限。

运行命令：`npm test`。

### 完整可玩闭环

脚本：`tools/test-playthrough.mjs`；机器报告：`screenshots/playthrough-report.json`。

- 移动、跳跃落地、修道院碰撞阻挡。
- 守卫对话并接受任务。
- 地图打开后暂停移动。
- 击败三只狼，药水消耗与恢复、技能和战利品。
- 采集两束草药，将任务推进为可交付。
- 交任务后 2 级、70 剩余经验、18 铜币（含一次战利品）、生命恢复。
- 背包、存档后刷新继续、死亡后庭院复活保留进度。
- 画质与音量设置、鼠标环绕、摄影、1280×720 布局。
- 常规流程没有运行时 console/page error，没有外站资源请求。

**自动化边界**：使用开发调试传送抵达测试坐标，以缩短移动时间；没有通过调试 API 直接完成任务、修改敌人生命或发奖励。并未据此声称已完成数小时人工徒步压力测试。

### 边界与回归测试：9项检查

脚本：`tools/test-edges.mjs`；报告：`screenshots/edge-report.json`。

1. 地形 GPU 顶点缓冲真实有起伏并可更新，不是视觉上仍为平面的高度数据。
2. 移动不会让 ArcRotate 镜头跟随半径漂移。
3. 设置值在重开窗口时保持，焦点在输入框时 Esc 也能关闭。
4. 在打开的背包中使用药水，数量和生命文字即时更新。
5. 摄影暂停玩法而不冻结镜头，导出有效的 PNG 图片。
6. 重置存档需要确认，取消不会丢存档。
7. 确认重置后不会被 beforeunload 自动保存写回。
8. 以上交互无页面错误。
9. 故意让屋顶贴图返回 404：必须显示加载错误并阻止进入，不展示纯色占位材质。

第9项是故障注入，网络/控制台中预期出现的错误不计为正常游玩的零错误承诺。

### 生产构建测试

脚本：`tools/test-production.mjs`；报告：`screenshots/production-report.json`。

- `npm run build`：TypeScript 无错误，Vite 构建通过。
- 本地生产静态服务器可加载标题、三维世界、地图、背包、设置与手动存档。
- 即使 URL 带 `?test=1`，生产构建也不暴露调试 API。
- 没有外部资源请求或常规运行时错误。
- 主 JavaScript 包约 1.23 MB（gzip 约 303 kB），另有按需模块与本地美术。
- 构建器仍提示主 chunk 超过默认 500 kB：这不是编译错误，未通过调大警告阈值隐藏它。

本机一次生产冷页面测试从导航到可见开始按钮约 3 秒，游戏 HUD 约 60 FPS。确切本次采样值见 JSON。这不是限速网络测试，也不是对所有显卡或手机的帧率承诺。

### 资源审计

`python3 tools/audit_assets.py --check`：**58 个美术/音频文件**全部有清单记录，大小和 SHA-256 相符。美术本地资源总计 16,945,697 字节。核心外部素材有成功下载记录与 CC0 页面/包内授权证据。

## 已修复的关键回归

- 透明植被错误显示黑色矩形。
- Thin instance 克隆共用顶点数据导致树冠消失。
- 地形缓冲不可更新，角色在坡上“悬浮”。
- 镜头目标 setter 在移动时重算半径，导致镜头越拉越远。
- 普攻开关被旧目标的攻击冷却拒绝。
- Esc 无法关闭聚焦了表单输入的设置窗口。
- 背包使用药水后弹窗数字不刷新。
- 删除存档被 beforeunload 又写回来。
- 资源失败提示被后续加载进度文案覆盖。
