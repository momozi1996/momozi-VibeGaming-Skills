# ALOHA KART · 夏日猫猫大奖赛

使用 Three.js 制作的原创、可玩的夏威夷猫咪卡丁车游戏。六只猫咪，八辆赛车，一条约 914 米的海岸环岛赛道。

## 立即启动

macOS：双击 `启动游戏.command`。已有 Node.js 环境时，首次运行会自动安装依赖并打开浏览器。

或在项目目录运行：

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。不要用 `file://` 双击 HTML；ES modules 需要 HTTP 服务。

## 操作

| 操作 | 键位 |
| --- | --- |
| 加速、刹车 | W / S 或 ↑ / ↓ |
| 转向 | A / D 或 ← / → |
| 漂移蓄力，松开冲刺 | Space / Shift + 转向 |
| 使用道具 | E |
| 回到赛道 | R |
| 暂停 / 恢复 | Esc |
| 三种驾驶镜头 | C |
| 明信片自由镜头 | P |
| 声音开关 | M |
| 全屏 | F |

触屏设备提供方向、油门、刹车、漂移和道具按钮。也支持标准映射手柄：左摇杆转向、RT 油门、LT 刹车、A 漂移、X 道具（浏览器映射不同可能有差异）。

## 已实现

- Mochi、Mango、Luna、Oreo、Sakura、Coco 六名可选车手；猫咪眨眼、摆尾，轮胎旋转、车身倾斜。
- 原创立体猫咪与圆润卡丁车，花环、花饰、轮胎纹路、镀铬轮毂、灯光与尾焰细节。
- 8 车同场，3 圈赛制，24 个顺序检查点，实时排名与成绩页。
- 手动驾驶、漂移蓄力和分级冲刺；越界减速、安全回正、车辆碰撞反馈。
- 鱼币、加速板、三种道具：加速、护盾、追踪投射物。
- 动态海面与浪花、椰林、遮阳伞、冲浪小屋、灯塔、火山岛、帆船。
- 粒子沙尘、漂移火花、冲刺轨迹、完赛彩纸。
- 原创程序合成海岛音乐与引擎、拾取、倒计时音效；首个交互后启用。
- 小地图、圈数、名次、速度表、漂移条；暂停、画质、静音与全屏。
- 明信片模式：鼠标拖动环绕、滚轮缩放、保存 PNG。
- 所有游戏资产本地加载，不依赖运行时 CDN、登录或后端。

## 构建与测试

```bash
npm test             # 16 项驾驶/道具/检查点/AI 单元测试
npm run build        # 生成 dist/
npm run preview      # 预览生产包
```

浏览器测试需本机 Google Chrome，先运行开发服务器再执行 `npm run test:browser`。macOS 测试使用 Metal；其他平台请移除 `tests/browser-smoke.mjs` 中的 `--use-angle=metal` 参数。

- `tests/browser-report.json`：端到端测试结果。
- `screenshots/`：菜单、赛道、暂停、完赛、明信片及手机视口截图。
- 测试覆盖选猫、帮助、开始、键盘加速转向、重置、暂停恢复、3 圈完赛、返回菜单、明信片和手机布局；控制台零错误/警告。
- 未抵达终点的 AI 时间以 `≈` 表示预计成绩，不冒充实际计时。
- WebAudio 已初始化并通过接口测试；自动化无头环境不能替代真人试听。

## 项目组织

- `src/main.js`：渲染、后期处理、光照、镜头、输入与模块整合。
- `src/track.js`：赛道、海岛、海面、场景及收集品。
- `src/racers.js`：六只猫咪、车辆建模和动画。
- `src/simulation.js`：比赛、物理、AI、道具和检查点。
- `src/ui.js` / `src/ui.css`：完整菜单、HUD 和响应式界面。
- `src/effects.js` / `src/audio.js`：粒子效果与程序音频。

用户要求的 5 个子 agent 已启动，分别承担赛道、角色、驾驶、界面、音效特效；赛道 agent 网络中断后由主 agent 接手完成。主 agent 负责集成及浏览器测试。

## 范围与素材

这是以成熟卡丁车游戏操作体验为参考的**原创浏览器游戏原型**，不是 Nintendo 官方产品，不使用其人物模型、贴图、商标 Logo 或音乐。画面目标是精致的风格化夏日动画，而不是宣称已达到商业 AAA 游戏的制作规模、内容量或跨平台认证标准。

当前提供一条赛道、单人对 AI；尚无联机、战役、专业物理轮胎模拟、移动商店打包等内容。建议使用启用硬件加速的桌面浏览器；低性能设备可在设置中降低画质。
