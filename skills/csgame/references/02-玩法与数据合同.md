# 玩法、状态与数值合同

权威来源：`assets/project/src/simulation.js`、`map.js`、`main.js`。机器数据：`assets/data/weapons.json`、`initial-round-state.json`。以下描述以实际运行代码为准，不以原HTML中等待刷新前的占位数值为准。

## 1. 状态机

```text
menu --真实点击Deploy--> startMatch/startRound --> deploy [3s]
deploy --> active [炸弹65s]
active --拆弹完成--> roundEnd [CT+1,4s]
active --死亡/超时--> roundEnd [T+1,4s]
roundEnd --任一方>=5分--> matchEnd
roundEnd --否则--> startRound
matchEnd --Deploy Again--> startMatch
活动状态 --Esc/失焦/商店--> paused=true （覆盖面板）
paused --Resume--> paused=false并重新请求pointer lock
```

- `phase` 与 `paused` 是唯一玩法状态；UI不能拥有另一个倒计时。`update` 在paused/menu/matchEnd立即返回。
- `dt` 每帧限制 `[0,0.05]`，是变量步进封顶而非物理subtick。低FPS时玩法时间可能慢于墙钟，不能宣称CS2真实时序。
- 新回合3秒部署期间不移动、不射击，炸弹65秒不扣减；部署里已设的reload/cooldown实际在active才推进。
- `roundEnd`4秒只推进尸体下沉/相位计时，不继续正常战斗。
- matchEnd结果面板，清输入、释放pointer lock；Replay清分数/金钱/主武器/杀死统计。
- `startMatch` 原实现不重置state.rng、保留difficulty；保留原行为，不为了“更随机/更公平”擅改。

## 2. 精确玩家模型

| 项 | 值 |
|---|---|
| 出生 | x=0,z=24,y=0 |
| 视角 | yaw=0,pitch=0，朝-Z；camera rotation order YXZ |
| 生命/护甲 | 100 / 50 |
| 站眼高/蹲眼高 | 1.7 / 1.13，按`min(1,dt*13)`平滑 |
| 地面半径/站碰撞高/蹲碰撞高 | .35 / 1.75 / 1.15 |
| 跑/走/蹲 | 5.6 / 2.65 / 2.05 m/s |
| 跳初速/重力 | 5.2 / 15 m/s² |
| 鼠标默认系数 | .0019 × sensitivity，狙击瞄准时.00062 |
| sensitivity | .3…2.5，默认1 |
| pitch范围 | 鼠标[-1.45,1.45]，射击后上限1.4 |

前/右输入各取-1/0/1，斜向长度>1先归一化；世界位移：
`dx=(-sin(yaw)*forward+cos(yaw)*side)*speed*dt`
`dz=(-cos(yaw)*forward-sin(yaw)*side)*speed*dt`。

跳跃仅落地时起跳，脚底y夹到>=0。原实现按住Space可落地再次起跳；不是单击跳跃事件。场景没有可行走屋顶/刚体台阶系统。

## 3. 枪械表

| slot | name | mag/reserve | damage | rate秒 | reload秒 | spread | recoil | price |
|---|---|---|---|---|---|---|---|---|
| rifle | AR-47 | 30/90 | 34 | .105 | 2.25 | .005 | .015 | 1800 |
| pistol | P-12 | 12/48 | 26 | .23 | 1.5 | .003 | .011 | 0 |
| sniper | SR-08 | 5/20 | 105 | 1.25 | 2.8 | .001 | .045 | 2400 |

- rifle在按住鼠标时重复尝试；pistol/sniper由main的`fireOnce`保证一次mousedown最多一发。只依赖rate会错误变成自动手枪。
- shoot前置：active、未暂停、活着、reload==0、cooldown==0、未拆弹。空仓发empty音并cooldown=.25，无子弹产生。
- 子弹方向从玩家眼睛发出，不从装饰枪口发出；先计算射线沿途最近墙，再比较head/body，不支持穿透。
- 爆头球：中心(bot.x,1.69,bot.z)，r=.19；body AABB：x±.25,y=.18…1.51,z±.22。实际模型几何不是逐三角形hitbox。
- 伤害：头×3，身体×1。死敌再次命中不再奖励。
- spread = 基础 ×移动3.8 ×蹲.6 ×瞄准.45；狙击未瞄准额外+.035。
- 射击增加pitch，yaw随机偏移±recoil*.15；视觉recoil加.22上限1，每秒回落2。不是CS2固定弹道图。
- reload填装min(缺口,reserve)，不创造弹药；满仓/无reserve不能装；切枪会取消reload并设cooldown=.3。
- 所有枪在新回合重新补满库存，但1键只拿当前primary，2键pistol；sniper需购买。

## 4. 目标与优先级

- SITE=(-6,-6)，水平距离严格小于2.8，脚底y<.1。
- E且无fire、forward、side、jump才能推进拆弹；瞄准/蹲不自动打断；开始拆弹取消reload。
- defuse>=5且time>0赢；每帧先扣time，因此已超时不能同帧靠拆弹抢赢。
- 离开/松键/移动/跳/射立即defuse=0。不能保留进度再回来接续。
- 所有bot死亡没有自动胜利条件；还要拆炸弹。
- 超时event explosion + T得分；死亡deaths+1 + T得分；endRound仅active有效，防止重复加分。
- armor吸收`min(armor,damage*.55)`；其余扣health，生命下限0。

## 5. 经济/轮次

- 初始money=2400，primary=rifle，CT/T/kills/deaths=0，round首轮=1。
- 每击杀+$300；赢+$2000；输+$1400；没有真实CS2连败系统。
- 买枪按上表，甲$650补到100。spawn半径<=6且phase为deploy/active允许；paused不禁止buy，因为商店本来暂停。
- 不足金额拒绝；满甲拒绝重复付费；切换primary立即装备并装满弹药。原版允许再次购买同一把主武器刷新库存（有足够金钱即可），不擅加另一套限制。
- 新回合恢复所有ammo、玩家health/armor/位置、bot数据、defuse/cooldown/reload。保留money、选中primary和比赛累计。
- 新比赛清money/primary/统计，不持久化比赛；只settings本地保存。

## 6. AI

初始三人数据见map.json，100HP，alive，初始fire=1.5+id*.4、repath=id*.3。

- LOS最大距离<34；从bot眼1.6到player实际eye，查询共享BLOCKS。
- 可见且距离<28：瞄准玩家并开枪；>9时按id方向.7m/s侧移且碰撞有效。
- 不满足开火近距路径时：A*寻路，2.3m/s；每1.6+rand秒更新；到路径点距离<.16换下一点。
- 前13秒未见玩家向A附近分点走；之后向玩家位置寻路。这意味着原AI有简单“知道玩家位置”的追踪，不是完全信息受限的竞技AI。
- easy/normal/hard `[基础开火间隔,基础命中率,伤害]` = `[1.45,.36,10]` / `[1.05,.48,13]` / `[.72,.67,17]`。
- 再加0…0.55秒射击间隔；>18m命中率×.65、玩家移动×.8、蹲×.85。命中用伪随机和LOS决定，不是bot武器实际飞行子弹。
- 随机LCG：seed15324，`rng=(imul(1664525,rng)+1013904223)>>>0`，结果/4294967296。声音/装饰FX仍可使用Math.random，不是全画面确定性回放。

## 7. API与事件

原单元测试按以下导出调用：
`createState,startMatch,startRound,update,shoot,reload,switchWeapon,buy,hitBot,hurtPlayer,endRound,WEAPONS`。

事件：`round,go,shot,hit,kill,hurt,reload,loaded,equip,empty,step,jump,botShot,roundEnd,explosion,matchEnd`，队列由main消费后清空；声音/特效不能反向决定真正胜负。
