# 运行、环境和原样恢复

所有路径以本 skill 为中心。本文用 `SKILL` 指 `csgame` 文件夹，`OUTPUT` 指新游戏工程，`REPORT` 指新证据目录。不要把示例环境变量当作脚本自动设置的变量。

## 依赖与环境

| 项 | 固定/建议 | 说明 |
|---|---|---|
| Three.js | 0.180.0 | 原渲染器、几何工具；不能用0.160替代 |
| Vite | 6.3.5 | 与锁文件一致 |
| Playwright | 1.55.0 | 测试依赖，不是游戏运行服务 |
| Node/npm | 原交付 Node 25.8.1/npm 11.11.0 | 建议现代 Node 22/24 LTS；本包不声称所有版本已实测 |
| Python | 3.9+ | 恢复/校验/HTTP工具，无额外pip依赖 |
| 浏览器 | 桌面Chrome/Chromium + WebGL2 | 原测试为macOS Chrome + ANGLE Metal |
| 输入 | 键盘鼠标 | 未实现手机触控 |

`assets/data/versions.json` 保存本轮真实源环境。操作系统/GPU/字体不同会影响截图；源文件hash不受这些因素影响。

## exact 恢复

```sh
python3 "$SKILL/scripts/repro.py" verify
python3 "$SKILL/scripts/repro.py" restore --out "$OUTPUT"
python3 "$SKILL/scripts/repro.py" compare --project "$OUTPUT" --scope all
cd "$OUTPUT"
npm ci --no-audit --no-fund
npm test
npm run build
python3 "$SKILL/scripts/repro.py" compare --project "$OUTPUT" --scope source
```

- restore 不拷贝 `node_modules`：平台特定的 esbuild/rollup 二进制由 npm ci 安装。
- 40个原快照文件包含源码、依赖描述、测试、dist、历史artifacts；首次恢复可完全按 SHA-256 验证。
- 原工程没有需保密的账号配置、API key 或服务器依赖。
- 构建成功并不保证新 dist 与原 dist 字节相同；原 dist 已保留用于精确恢复。
- 对源码 exact 校验使用 `--scope source`，它排除dist和历史artifacts，只检查对应源文件是否改变，同时报告额外文件。
- `restore/scaffold` 拒绝非空目录、输入资产内部、已有文件等风险路径。

## 本地运行

默认 `npm run dev` 监听4399，`npm run preview` 监听4400，都只监听127.0.0.1。原会话可能已有服务器占用这两个端口；换一个空闲端口，不杀陌生进程：

```sh
# 在OUTPUT执行，直接调用当前已安装Vite，避免脚本预设port冲突
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 4411 --strictPort
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 4412 --strictPort
```

原成品可以零npm安装运行：

```sh
python3 -m http.server 4410 --bind 127.0.0.1 --directory "$SKILL/assets/project/dist"
```

不能使用 `file://`。dist内使用根路径，简单静态服务把dist作为根目录；若改为网站子路径部署，需要单独处理base，不属于exact原样运行。

## 原始测试与可携验收

原 `tests/browser.mjs` 读取 `TEST_URL` / `CHROME_PATH`，默认macOS Chrome且写 cwd/artifacts。原 production 脚本固定4400。为保持其字节不变，本包提供 **外层适配器**：

```sh
node "$SKILL/scripts/check.mjs" --project "$OUTPUT" --out "$REPORT"
```

适配器只把原脚本中的浏览器加载、平台参数、URL和证据路径替换到临时文件，并先关闭WebGL页面再关闭浏览器以避免Metal退出挂起；不删断言、不改测试流程，原测试保留不动。它使用**本包基准测试**验证OUTPUT实现，防止被测项目悄悄缩减用例。自动选择空闲端口，启动/停止自己的Vite进程；序列运行开发和生产以降低GPU争用。

Chrome路径选择：`--chrome` > `CHROME_PATH` > 常见本机安装 > Playwright已安装浏览器。找不到就报可操作错误。可显式安装：在OUTPUT执行 `npx playwright install chromium`（会下载浏览器；由用户/运行者决定，不是本包自动全局安装）。Linux需要满足浏览器系统依赖。

## 网络与离线边界

- **dist运行离线**：场景、模型、程序纹理、声音和字体fallback均本地，无CDN。
- **开发首次安装非保证离线**：没有node_modules或全平台npm缓存；npm ci需网络/缓存，Playwright浏览器另需本地安装/下载。
- 原锁文件 `resolved` 使用 `https://registry.npmmirror.com/`，版本/integrity固定。`npm ci --registry=...` 不一定覆盖每个锁定URL。
- 镜像不可用时，优先使用可访问网络/缓存。若用户授权替换输出锁文件中的registry前缀，只改resolved host、不改版本和integrity，记录该差异；这样的输出锁文件不再能称“源文件100%exact”。不可修改本包原锁或SHA清单。
- 不通过 `npm update`、`--force`、删锁文件重新解析来掩盖依赖问题。
