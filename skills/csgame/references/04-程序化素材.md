# 程序化素材：完整源与可复用实物

## 1. 权威素材清单

| 分类 | 权威源 | 包含 |
|---|---|---|
| 场景/纹理 | `assets/project/src/world.js` | plaster/stone/pave/wood canvas纹理；所有院落几何与装饰；炸弹 |
| 武器/手臂/敌人 | `assets/project/src/models.js` | AR-47/P-12/SR-08、枪口闪光、手套/袖口、分段soldier |
| 音效 | `assets/project/src/audio.js` | WebAudio噪声、振荡器、滤波/包络 |
| 雾/灯光/远山/FX | `assets/project/src/main.js` | 灯光初始化、视角、动态子弹/爆炸/尸体表现 |
| HUD/菜单 | `assets/project/index.html` + `src/style.css` | 全部HTML/CSS、内联data favicon、系统字体 |
| 第三方运行库 | `package-lock.json`中three | 不是素材下载服务 |

**原项目没有外部GLB、PNG贴图库或WAV文件。** “完整素材”首先是以上生成源码；所有参数都在本包，不依赖原作者服务/API。

## 2. 已导出的素材

`assets/extracted/`由本包`export-assets.mjs`实际运行程序化源码生成，提供：

- `world.glb`：静态院落和炸弹几何/纹理，不含main里的天空/雾/远山；不能将GLB整体当作完整游戏。
- `weapon-rifle.glb`、`weapon-pistol.glb`、`weapon-sniper.glb`：带手臂的静态枪械。
- `soldier.glb`：分段敌人模型；原动画由main逐帧旋转关节驱动，因此GLB **没有AnimationClip**。
- `textures/*.png`：当前world与models材质贴图/凹凸共用图；清单记录来源材质与repeat。重复贴图只导出一次。
- `map-topdown.svg`：map.json生成的布局图。
- `asset-index.json`：真实导出文件、尺寸/对象统计、来源说明。

不要把导出的GLB声称官方模型或带完整骨骼动作。runtime仍以程序化源码为真值；复用GLB需自己处理坐标、材质、碰撞和动画接口，不是简单替换文件名。

## 3. 世界建模参数

### 纹理

- texture canvas 512×512，世界种子初始3489；LCG世界随机与simulation rng分离。
- 22000个细噪声粒子；stone/pave有错缝，wood有竖向木纹和板缝，plaster有大面积风化斑。
- SRGB，RepeatWrapping，anisotropy=4；pave repeat(14,14)，其余通常(2,2)。ground为180×180m，因此不能把“14次重复”误设成每米14次。
- 地面底色#b9b096；墙#cbb68c，亮墙#e2d2b0；stone#b7a581；wood#998260；blue#467c81。
- plaster/light/stone/wood/blue/sandbag复用颜色纹理作bumpMap；wood bumpScale=.025，其余.045。roughness多为.88…1，不是金属发亮墙。
- 模型近景纹理canvas256×256，独立seed91；枪木#805237/#513d2c、衣#747968、背心#343f3d，bumpScale=.004。

### 静态几何与批次

world用材质分批合并，不把每块窗条建成单独draw call。Box/Cylinder/Sphere/Extrude/Tube/自定义BufferGeometry混用时：

1. indexed先toNonIndexed；
2. 缺UV补长度匹配的Float32 uv属性；
3. compose世界变换→applyMatrix4；
4. mergeGeometries后建立Mesh，shadow on；
5. 释放已合并临时geometry。

少这一步会报`.mergeGeometries() failed`并白屏，原开发已真实遇到。

### 拱门

半宽5，y基线1.15，高方向半径3.3，20段Shape/Extrude depth3，位于z10.5…13.5。浅色环外半宽5.35，高方向3.65，前后边缘略错开避免z-fighting。独立左右门柱；门匾“AL SAFRA”，两侧“A ←”涂记；上方矮建筑和护栏。

### 院落与道具

- wood箱：底/顶横木，侧竖木，顶部金属箍，↑↑字符贴面。
- sandbag：按行列堆叠压扁Sphere，不是一堵实心方墙的最终视觉。
- barrel：两圆桶+金属箍，但仍按原BLOCKS总体AABB碰撞。
- 百叶窗：暗凹槽、青蓝窗、白边框、深色横百叶；左右建筑窗改朝向，不能只做正面。
- 后门、storage牌，遮棚条纹布，盆栽，屋顶机箱、天线、蓝水箱、碟形天线。
- 电线：三组垂落CatmullRomCurve3 + Tube(.022)，不是直线一笔替代。
- palm：tube树干，11条叶轴，每条两侧16节小叶；保留当前羽叶版，不回退到早期大块三角伞。
- 远景24个低多边建筑/部分圆顶，远山在main构建；雾压低远景对比。
- 炸弹：黑盒、3根横放小管、绿屏、闪烁橙LED、PointLight；真正位于SITE地面。

## 4. 枪械和角色

- 世界模型坐标与viewmodel坐标分离：枪默认朝-Z；bot持枪绕Y转π缩放.68，角色正朝+Z。
- 枪用RoundedBoxGeometry（bevel radius=min(w,h,d)*.12）、Cylinder、Extrude弧形弹匣；不是把整枪画进PNG。
- weapon返回Group，`userData.flash`引用可显隐枪口闪光组；所有runtime变换由main负责。
- makeBot返回Group，`userData.legs/arms/gun/flash`；腿随walk相位摆动，死后全体倾倒/下沉，不是rig/skin。
- 角色头盔、护目镜、脸遮布、背心/弹匣袋、裤子、护膝、靴子、双臂齐全；保持约1.8m的人体尺度，碰撞和hitbox并非自动由mesh推断。
- 序列化GLB中的userData不能保留Three对象引用：导出器暂时去除这些引用，源模型不改。

## 5. 音效

AudioContext只在真实用户操作后init/resume，master volume默认.6，可0…1。

- shot：低通noise+160Hz下落triangle+短高频square；sniper noise更长。
- botShot：较低音量短噪声；step按quiet减音量；reload/loaded/equip机械短声；empty短click。
- hit：noise+三角音，headshot更高；hurt低频噪声。
- bomb beep1500Hz；间隔剩余>=25s时1.3s，10…25s时.7s，<10s时.35s。
- 爆炸：1.6s低通噪声和90→20Hz正弦。

这些是合成音，不是实录枪声。自动测试没有主观听感证明；没有额外WAV资产也不代表缺素材。为了1:1，优先复现AudioSystem，不临时下载网上枪声替换。
