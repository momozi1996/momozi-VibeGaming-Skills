# 验收与证据

## A. 包与源文件

`repro.py verify`验证skill内manifest引用的40个基准文件hash/字节数；默认同时验证skill根目录的SKILL-MANIFEST全部列出的文件与路径集合。它证明资料完整，不证明游戏运行。

`restore`完成后`compare --scope all`：复制是否字节一致。运行build后`compare --scope source`：源码/测试/锁/许可不改变。额外产物报告为extra，不直接判已有文件不一致；不要把source通过说成额外代码也已审计。

## B. 本轮完整回归

```sh
node "$SKILL/scripts/check.mjs" --project "$OUTPUT" --out "$REPORT"
```

项目先npm ci。原合同测试由**skill只读副本**读取，临时替换环境依赖不修改断言。`--suite core`仅单元+build；默认all包括开发+生产。实际日志、summary.json、新截图放REPORT；不能写回asset原报告。

- 单元文件用file URL导入重定位到OUTPUT/src，避开复制旧源执行的伪验证。
- node:test断言定义：`assets/project/tests/simulation.test.js`。
- browser断言定义：`assets/project/tests/browser.mjs`。
- production断言定义：`assets/project/tests/production.mjs`。
- 不支持的GPU/缺浏览器会明确失败，不能静默skip当通过。
- 测试慢机器可能因真实墙钟输入窗口/性能不足失败；先记FPS/GPU，不以提高固定移动量/删断言绕过。

## D. 原23项开发浏览器合同

菜单渲染；真实deploy捕鼠；W位移；鼠标转向；撞墙；过拱门；蹲/跳；真实弹道被墙挡；真实爆头；R装填；pistol按住只打一发；Tab；解锁暂停/恢复；买sniper与scope；拆弹中断；完整拆弹；下一回合；爆炸输；死亡输；先5分结果；replay；blur释放；零正常流程console/HTTP错误。

使用`__counterline.fixture`放置角色/设置时间与分数，以缩短测试；**没有宣称无人干预地自然打完多局**。完成目标、射击和移动仍由真实键鼠触发。

## E. 原10项生产合同

DEV fixture absent；鼠标打枪扣弹；R补弹；W穿过出生区；pause冻结；settings/menu；刷新保存；720p与1080p布局；损坏storage回退；正常流程无console/HTTP错误。

生产test完全不依赖fixture，不要在生产保留后门只为图省事。WebGL不支持的故障注入是单独测项，renderer预期错误不能与正常流程失败混淆。

## F. 开发夹具API（重建要兼容）

只在`if(import.meta.env.DEV)`块赋值，Vite生产消除：

```js
window.__counterline = {
  state, // 唯一simulation state
  snapshot: () => ({
    phase, paused, player, ct, t, round, reason, kills, deaths,
    time, defuse, ammo, slot, money, bots, shots, fps
  }), // 实际返回深拷贝JSON，字段来自当前state
  fixture(options) { /* 只merge下面白名单，不触发伪造胜利 */ },
  hurt(damage) { hurtPlayer(state, damage); },
  hit(id, damage, head=false) { hitBot(state,id,damage,head); }
};
```

fixture：player对象merge；phase/time/ct/t/round/phaseTime可设置；bots数组按索引merge。不能用fixture在production中代替DOM。fps来自真实rAF间隔的近期样本，不写静态60。

## G. 视觉与固定视角

```sh
node "$SKILL/scripts/capture.mjs" --project "$OUTPUT" --out "$NEW_CAPTURE_DIR"
```

该脚本从待测项目启动开发服务，用真正Deploy进入，然后只在DEV里设固定state/相机，暂停simulation但仍渲染，生成统一inspect-menu/spawn/site/defuse/armory/scope/result截图和环境JSON。它是一套**截图夹具**，不是额外7次通关证明。也可先对原exact副本拍，再对rebuild同脚本拍。

历史gameplay.png来自过程型输入测试，各个时刻可能不同；不要直接与固定inspect-site按像素作严格等同。对齐viewport、DPR、镜头、player/bot、时间和设置，优先评价场景形体/比例/UI功能，不为像素误差胡乱改物理坐标。

最少实际查看菜单、出生架枪、A点、敌人、拆弹、scope、armory、result；注意枪被near clipping截断、阴影漏/全黑、字体fallback、底栏挡视野、图像与碰撞不一致。
