# 排错、已知边界与禁止误述

| 现象 | 原因/检查 | 正确处理 |
|---|---|---|
| 白屏，mergeGeometries报attributes/index不一致 | Box等indexed，Extrude非indexed，手工叶片无UV | merge前统一toNonIndexed并补UV，不给null创建Mesh |
| waitForSelector('#loading.hidden')超时 | 它在等待“可见”，但hidden本来display:none | 等`#loading` state:hidden，不是错误修改游戏 |
| Resume后立刻B没响应 | pointerlockchange异步，测试抢在业务locked更新前 | 等真实捕鼠事件完成/短同步等待，不删除B断言 |
| Tab按press后看不到记分 | press包含down+up | 用keydown保持，assert后keyup |
| 手枪像自动步枪 | 只有cooldown无fireOnce门控 | main按mousedown消费单次；rifle才hold自动 |
| 武器把屏幕完全挡住/切断 | 位置太近、stock穿相机、错误scale或第二camera | 对齐weapon近裁剪、position(-.68 z)、.72 scale和clearDepth渲染 |
| 某机器移动量断言失败 | GPU无加速/多Chrome争抢/低FPS、dt封顶 | 记录实际FPS，正确Chrome后端；串行测，不假改速度 |
| 打到远处敌人但穿过近墙 | 未比较墙的最近命中距离 | 先wall distance，再bot hit nearest |
| 拱门走不过 | lintel忘了y=4.4，被当作从地面起 | 高度同map.json，控制碰撞不能只画拱门贴图 |
| 无声 | AudioContext未从用户手势启动/浏览器静音/音量0 | init/resume挂真实click，检查master；不宣称测试听过 |
| localhost4399/4400冲突 | 原工程仍在运行 | 随机新端口或手动4411；不杀其他服务 |
| 导出GLB报循环引用 | userData引用其他Object3D | 导出副本/临时清userData，别破坏runtime模型引用 |
| npm ci镜像不可用 | lockfile resolved指npmmirror | 检查网络/缓存；授权后只改输出resolved并报告差异 |
| Playwright缺浏览器 | npm包不等于浏览器二进制 | 设置CHROME_PATH或显式npx playwright install chromium |
| Vite JS>500kB提示 | Three打入一个chunk | warning不是失败；不抬阈值冒充优化 |

## 已知原型边界（保真时应披露）

1. 本地单人1v3，不存在联机、账号、匹配、服务器权威、CS2 subtick。
2. 一个原创地图，一个A点，固定有限掩体；不是Dust II，也不使用官方CS2素材。
3. 玩家射线简化球/盒hitbox，AI攻击基于LOS+概率；无子弹下坠、穿墙、后坐模式表、CS2真实伤害衰减。
4. 地图AABB碰撞，拱门曲面装饰/窗沿/细碎物体不逐三角形物理；无可行走屋顶/可攀箱系统。
5. 枪、人都程序化几何，动画为刚体变换；GLB导出不含骨骼clip。
6. 木纹等是canvas生成而非照片扫描；系统Impact/Arial字体不随包分发，跨OS外观可能变化。
7. 爆炸烟火和子弹是视觉效果，不带地图破坏。
8. 没有手雷、刀、捡枪、全武器库、真正CS2购买期/经济/输赢语音。
9. 暂停/商店会冻结当前单人回合；刷新不保存比赛，只保存设置。
10. 仅桌面键鼠，响应式CSS不等于手机控制可玩。
11. 暂停冻结simulation/主要效果时间，但菜单背景/部分视觉闪烁可继续，不能宣称全渲染冻结。
12. 目标1:1的输入/行为也包括现有简化；用户要修缺点时另开variant并列差异，别悄悄改exact基准。

## 不应该做

- 没有错误日志就为了“make no mistakes”反复无边界重装/升级。
- 用参考PNG铺满canvas冒充3D；用自动开枪/自动拆弹冒充真输入。
- 复制历史test报告或跳过失败用例声称全部通过。
- 全局安装、公网部署、上传素材、调用收费API，除非用户另外要求。
- 修改输入manifest后称素材未变；source对齐不等于未知新增代码也验完。
