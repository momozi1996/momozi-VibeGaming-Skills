## Viewmodel原比例

- scale=.72；常态position≈(.28,-.27,-.68)，角度x≈0,y=.10,z=-.015。
- ADS x趋近.014，y+.09；recoil z+.13*recoil，x角+.16*recoil。
- reloadProgress=1-reload/duration，sin(progress*PI)控制下沉/偏转，不能只换文字无动作。
- defuse>0再下沉.2；行走以elapsed*13的sin bob影响眼高与武器。
- 原始近景缺点：非PBR扫描模型，动作是刚性程序变换；不要过度美化导致不再对齐。

## 输入事件的非显然约束

- 初始按钮必须真实click来获取pointer lock与AudioContext权限。
- pointerlockchange异步；`document.pointerLockElement`刚不为null，业务locked变量可能还没完成事件处理。自动测试在获取后额外等120ms，不误判B键失效。
- move mouse只在locked且非paused时更新yaw/pitch；右键需要屏蔽contextmenu。
- mouseup不受locked限制，必须释放fire/aim；blur与visibilitychange也clearInput。
- held集合用KeyboardEvent.code，忽略重复按下的单次动作；WASD、C、Ctrl、Shift、Space、E为持续输入；R/1/2/B为边沿。
- Tab keydown显示计分，keyup隐藏；`keyboard.press('Tab')`包含松开，断言显示必须用down而不是press。
- 商店/暂停/结果释放pointer lock时不能被pointerlockchange误改成另一个面板；activeOverlay记录当前覆盖层。
- Resume清输入后重新请求锁定；失败留可点击恢复提示而非游戏后台继续走。
- Escape由浏览器释放锁引出pause；设置里Esc只返回上层面板，不执行额外玩法动作。

## 设置与适配

- storage key `counterline.settings.v1`；仅 sensitivity/volume/difficulty。
- JSON损坏、无存储权限不阻止启动；数值finite+clamp；difficulty白名单easy/normal/hard。
- <780高菜单缩字，<900宽缩雷达隐藏底提示，<600保留菜单按钮但不等于实现触控。
- 实测目标1440×900/DPR1；1280×720与1920×1080无横向溢出、按钮不出屏。
- 不能只说“响应式所以手机可玩”；手机缺键鼠操作属于原版非目标。
