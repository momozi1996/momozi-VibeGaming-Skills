# 工具参数与文件定位

所有新工具仅用Python标准库或OUTPUT中已安装的Node依赖，不使用全局CLI、外部技能、用户个人路径。传入含空格路径时加引号。

| 工具 | 参数 | 输入/输出 |
|---|---|---|
| game.py create / play | `--out NEW_DIR [--port 4410]`（port仅play） | 原样恢复并加便携start-demo.py；play直接运行dist，无需npm |
| start-demo.py（输出工程中） | `--port 4410` | 重启已生成项目；0自动分配端口 |
| repro.py verify | 可选 `--baseline-only` | 检查只读基准40文件；默认同时校验根SKILL-MANIFEST全部文件 |
| repro.py restore | `--out NEW_OR_EMPTY_DIR` | 原字节复制，自动再次compare all |
| repro.py scaffold | `--out NEW_OR_EMPTY_DIR [--seed-art]` | 新建rebuild工程基础；没有入口/业务代码，不是即开即玩 |
| repro.py compare | `--project PROJECT [--scope source\|all]` | 源差异和额外未审计文件；发现内容差异返回非0 |
| check.mjs | `--project PROJECT --out NEW_REPORT_DIR [--suite all\|core] [--chrome PATH]` | 使用基准测试，自动随机端口，单元→构建→开发→生产 |
| capture.mjs | `--project PROJECT --out NEW_DIR [--chrome PATH]` | 固定状态截图，用于外观对照，不算通关测试 |
| export-assets.mjs | `--project PROJECT --out NEW_DIR [--chrome PATH]` | 从程序化源导出5个GLB、材质贴图、布局SVG |

- `--help`显示每个工具帮助。
- Node类工具使用已恢复/重建的项目，拒绝直接在skill的基准路径运行，以免写node_modules或Vite缓存污染输入。
- 新报告目录必须不存在；Python restore/scaffold额外接受已存在的空目录。不要把新报告输出到package里；本包内的assets/extracted由打包者先在临时目录导出后拷入，详细本轮验证在仓库verification/csgame。
- `CHROME_PATH`可指定Chrome/Chromium；`ANGLE=metal`或`ANGLE=default`可覆盖后端。默认macOS使用metal，其他OS不强行传Metal参数。
- 自动选择端口存在极小的占用竞态，若服务器在选择后被其他进程抢占，脚本会失败并报告，不杀别的服务。
- 正常退出/失败会关闭自己spawn的Vite；若外部强制中止进程，可由运行者检查日志所示PID/端口后只清理该任务进程。

## 读文件优先级

1. SKILL.md确定模式和范围。
2. references按当前阶段读取，不一次把所有大文件塞给小上下文模型。
3. assets/data机器JSON获取精确数值与地图。
4. assets/project/src是权威实现，原tests是合同。
5. assets/project/artifacts是历史参考图/证据，assets/extracted是辅助导出。
6. assets/BASELINE-MANIFEST.json只供机器校验，不必全文给语言模型。

## 只想给模型发送少量附件

最少：对应主提示词 + SKILL.md + 02/03/04/05/07 references + map/weapons JSON + menu/gameplay/scope/armory PNG。**这不是完整精确恢复包**，只适合重写参考；exact必须交完整assets/project和脚本，不能只给截图要求模型猜全部代码。

完整压缩包才保证所有项目文件、许可证、素材生成参数、构建成品与测试可以一并转交。
