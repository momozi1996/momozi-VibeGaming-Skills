# 灯火小径：玩法与实现地图

## 完整流程

选塔 → 点击地基建造 → 开始波次 → 战斗赚币 → 升级或拆除 → 守完所有波次 / 灯火耗尽 → 重开。

建造必须扣足费用；升级最多 3 级；拆除按已投入费用折返 65%。星晶单点，霜铃范围减速，烛火范围伤害。每波手动开始；敌人沿同一路径前进，越过终点扣灯火，击杀奖励一次。

## 文件所有权

- `assets/project/game-config.json`：两套真实主题、设计文本、配色与关卡/节奏参数。`defaultTheme` 可选择默认主题。运行时加载 JSON，不需要编译。
- `src/game.js`：本类型唯一游戏实现。`TOWERS` 定义塔价/射程/攻击间隔/伤害；`path/lengths/point` 定义同一条逻辑路线；`pads/towers/enemies` 负责状态。
- `src/main.js`：菜单、主题切换、暂停、终局、输入、触控、音效开关、全屏、HUD 适配。
- `src/art.js`：绘制库、固定随机数、图片加载、天空/植物/粒子等。
- `src/audio.js`：浏览器手势解锁后的本地合成音效；不是在线音乐或已录制配乐。
- `public/art/`：20 个可编辑 SVG，含角色、敌人、建筑、植被、作物、晶塔等。
- `tools/draw_art.py`：原创素材源稿。只在明确要重生成时运行，会覆盖项目内同名 SVG；先保存手工编辑。
- `style.css`：布局、纸感色彩、字体、不同屏幕尺寸与 UI 状态。

## 时间、空间与数据

逻辑画布 1280×800；事件通过 canvas 的实际 rect 映射回逻辑坐标。CSS 缩放不能直接当世界坐标。时间 dt 以秒计且限制单帧大跳跃，暂停不推进 update；动画 t 可以继续。首屏所有 SVG 成功加载才开放开始，缺资源明确报错。

主题的 `seed` 用于固定布置。支持的是两套内置主题与用户继续改造，不是任意语言一键生成地图的独立模型。详见项目 `game-config.json` 的实际字段，不凭示例名推断已实现系统。

## 内置两套主题

- `lantern`：默认完整作品。
- `snow`：独立视觉配置，并具有节奏/路线/订单等实际差异。

固定路线与预设建造点的塔防；不是已有自由堵路/迷宫寻路或植物大战僵尸格线系统。
