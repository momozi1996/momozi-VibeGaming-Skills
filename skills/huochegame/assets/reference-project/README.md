# CLOUDLINE · 云间慢行

一辆森林绿的电车，两座云海中的小岛，一段不必匆忙的海岸旅程。

## 直接游玩

双击 **`cloudline.html`**，用支持 WebGL 的 Chrome / Edge / Safari 打开即可。
**无需安装、无需服务器、无需网络。** Three.js、界面、模型、纹理和音效全部包含在约 760 KB 的 HTML 文件中。首次按键/点击后浏览器才会允许播放音效。

### 慢行的秘诀

- 默认 12 / 16 名乘客，从 **Saltlight Terminus** 出发，驶向 **Mango Tide**。
- 725 m 的连续环线有上坡、下坡、高架弯道和跨海长桥；往返两段线路自动衔接。
- 一直按住动力会太快。轻点动力，在约 **24–34 km/h** 之间巡航，转弯或侧风时再慢一些。
- 大约剩 **65 m** 时开始减速，以 **不超过 7 km/h** 接近停车点。停车点前 11 m 内会辅助对位。
- 高速越过停车点会触发**安全制动**：舒适度和连胜受到惩罚，不能获得平稳到站的小费。
- 停稳后按 E 开门，等待约 7 秒让乘客上下车，车门关闭后再出发。
- 每次真实停站只结算一次车费。平稳到站额外 **+75** 小费，持续连胜逐次增加。
- 急加速、急刹、高速过弯和侧风会降低舒适度。温柔驾驶会逐渐恢复。

## Oliver 的工坊

出发前，或到站开门前，可切换到独立的等距工坊：

1. **炉火叶片**：拆下旧部件，升起车顶并装配新叶片。
2. **小小伙伴**：装上绿色顶棚、行李架、额外行李、灯笼与藤蔓。
3. **全员上车**：电车实际驶出工坊，返回当前车站，再继续海岸线。

首轮改装免费。完整完成两步才保存改装；只做第一步后提前退出会取消未完成的改装。改装完成后加速性能略增，舒适度损失减少 22%。

货币与完整改装保存在当前浏览器的 localStorage；存储不可用时仍可正常玩。重新开始只重置本趟旅程，保留货币与改装。不同浏览器对 file:// 存储隔离策略可能不同。

## 文件说明

- `cloudline.html` — **唯一必需的运行文件**，直接分享这个文件即可。
- `src/game.js` — 可读、有分区注释的游戏代码；状态机、物理、世界、角色、输入、音效与 UI。
- `src/style.css` / `src/shell.html` — 界面源码。
- `src/three.inline.js` — 内嵌的 MIT Three.js r160，仅引擎经过压缩。
- `build.mjs` — 用 Node.js 内置模块将源文件重新组合为单个 HTML：`node build.mjs`。
- `tests/report.json` / `screenshots/` — 本轮回归报告和截图。
- `GAME-CONTRACT.md` / `PROGRESS.md` — 范围、已实现内容与验证边界。

## 开发与验证（游玩不需要）

```sh
node build.mjs
npm ci
# Chrome 自动化测试；非 macOS 请设置自己的 Chrome/Chromium 可执行文件路径
CHROME_PATH="/path/to/chrome" npm test
```

测试中的 `?test` 查询参数显式开启夹具；普通打开时没有传送 / 快进调试入口。路线全程测试使用 60 Hz 时间压缩控制器真实推进驾驶物理，键盘、暂停、触控按钮用浏览器真实时间操作；不把这些称作长时间人工驾驶。

程序化视觉是原创轻量化的低多边形实现，不包含原作素材。不是完整车辆刚体模拟：电车约束在轨道上，不会脱轨。移动端已通过 390×844 浏览器尺寸与触控事件验证，未对所有实体手机或 Safari 版本进行兼容性 / 性能认证。
