## 修正记录

- 显示的角色 age 曾领先碰撞一帧，现统一先推进状态、后判定、再显示同一 age。
- 空中攻击落地会立即结束空中招式，避免落地后“悬空踢”。
- 起跳与下落动作按垂直速度阶段选帧，避免下落直接跳过完整动作。
- 重击命中停顿期间输入仍被记录，缓冲寿命不被停顿耗尽。
- 去除道路切片中的透明分隔列，车与道具移至战斗线后方，避免角色站在车上。

## 已知边界

并非商业级完整格斗游戏：美术来自 CC0 原生精灵，保留源分辨率并按统一人体高度绘制，非商业级重绘；招式为原创帧表，未声称复刻 KOF 参数。碰撞使用按状态/招式阶段配置的矩形组，不是 KOF 逆向数据或逐像素碰撞。只有一场景、两角色、一招必杀/人；无联网回滚或手柄。移动竖屏可操作但画面较小，推荐横屏或桌面。
