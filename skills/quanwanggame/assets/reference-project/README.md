# NEON IMPACT / 霓虹对决

原创角色、经典街机节奏的网页版 2D 格斗 Demo。使用真实 CC0 精灵和像素街景，不含 KOF 拆包素材、商标或原声；不是任何一代 KOF 的逐帧复刻。

## 直接试玩打包版本

压缩包已包含 `dist/`，无需安装 npm 依赖。在项目目录执行 `python3 start-demo.py` 即可自动打开浏览器；macOS 也可运行 `打开游戏.command`。

## 开发启动

需要 Node.js 20.19+（测试环境 Node 25）。

```sh
npm install
npm run dev -- --port 5196
# http://localhost:5196
```

生产构建：`npm run build`，把 `dist/` 完整部署到站点根目录即可。`dist` 也可使用 `python3 -m http.server 5196 --directory dist` 本地运行。不要直接双击 HTML（ES module 和资源加载需要 HTTP）。运行时不访问第三方素材站点，没有 CDN、登录、API 密钥或后端需求。

## 内容

- AVA / 赤燕：快速移动与前冲裂空踢。
- REN / 玄武：较稳重的拳脚与远程破空劲。
- 人机对战、本地双人、训练模式。
- 前后移动、跳跃、蹲下、背向防御、轻重拳脚、空中攻击、蹲攻、每人一招必杀。
- 下 → 下前 → 前 + 轻拳/重拳（20 逻辑帧内）；或一键辅助。必杀没有能量门槛，以起手、收招和距离限制滥用。
- 命中/防御确认后，普通攻击只在配置的窗口可取消到必杀；空挥不可取消。
- 60 秒回合、两胜制、超时判定、相杀、回合/胜负播报；平局不计胜场。
- Hitstop、击退、命中特效、雨夜街景；可选的原创合成节拍。

## 操作

| 操作 | P1 | P2 |
|---|---|---|
| 左 / 右 / 跳跃 / 蹲 | A / D / W / S | 方向键 |
| 轻拳 / 轻脚 | J / K | 数字小键盘 1 / 2 |
| 重拳 / 重脚 | L / I | 数字小键盘 4 / 5 |
| 必杀辅助 | U | 数字小键盘 0 |
| 防御 | 相对对手后方向；下后防低段 | 同左 |

`ESC` 暂停，`F2` 判定框和输入历史，暂停时 `N` 前进一逻辑帧，训练时 `R` 重置。切标签/失焦自动暂停，恢复需手动继续。选人界面以 ← → 选角色、↑ ↓ 切换模式、Enter 开始。界面提供音效开关、全屏、完整说明。手机有触控按钮，桌面键盘/横屏体验最佳；本地双人需要数字小键盘。

## 架构

- `input/`：键盘/触控、6 帧动作缓冲、方向指令识别、带种子的 CPU。
- `fighters/`：角色参数、FSM 与招式定义。
- `combat/`：固定 60 Hz 模拟、回合、伤害、取消、防御、相杀。
- `collision/`：独立 AABB Hitbox / Hurtbox / Pushbox；双方命中先收集再统一结算。
- `animation/`：固定锚点精灵帧，按启动/有效/恢复阶段重定时。
- `rendering/`：PixiJS 场景和特效，不能改变判定/生命值。
- `audio/`：Web Audio，播放 CC0 OGG；声音失败不阻断游戏。
- `ui/`：独立读取战斗快照，血条插值不影响生命值。
- `debug/`：逐帧状态显示。

启动帧采用 **纯启动时长**，即 `0..startup-1` 无攻击框，`startup` 开始有效。与部分网站“第几帧命中（包含首有效帧）”的表示法相差 1。招式参数是原创设计，非 KOF 原版数据。

## 验证

```sh
npm test          # 逻辑单元测试
npm run build     # TypeScript 与生产构建
npm run test:browser  # 先启动 5196；使用本地 Chrome + Playwright
```

`evidence/` 保存浏览器截图和报告。浏览器调试接口仅开发环境或 URL `?debug=1` 启用：`window.neon.match`、`setPause()`、`tick()`。该接口用于可重放的测试情境，不属于普通玩法。

## 素材与边界

见 `docs/ASSETS.md`、`docs/asset-manifest.json`。图集导入脚本为 `tools/prepare-assets.py`（Python 3 + Pillow + requests），包含原始下载地址及校验记录。角色是授权精灵重新编排后的 Demo 角色别名；角色精灵保留源像素，以独立根锚点匹配身高，画布适配窗口和 DPR，并非商业级逐帧重绘。

尚未实现：联网回滚、手柄、3v3、投技、KOF 小跳/大跳/翻滚、精确原版帧表、更多角色或场景。无独立 “K.O.” 人声，使用 K.O. 文字+原创合成音与回合/胜负播报。不冒充素材包含有未提供的声音。
