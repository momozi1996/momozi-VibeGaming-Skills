# 03｜玩法、操作与可复现流程

## 模式 / 人物

| 模式 | 实现 |
|---|---|
| ARCADE / 人机 | P1 对带固定随机种子的CPU，普通难度 |
| VERSUS / 本地双人 | 两个玩家共用同一键盘；P2需数字小键盘 |
| TRAINING / 训练 | 对手空输入、计时不减；可暂停逐帧，R重置 |

AVA / 赤燕：CRIMSON TEMPO，移动3.8 px/tick，起跳vy12.5，快速前冲裂空踢。
REN / 玄武：IRON CURRENT，移动3.2 px/tick，起跳vy12.1，破空劲投射物。

只有P1选人；另一角色自动作为P2/CPU，不支持同角色镜像战或队伍选择。

## 操作表

| 行为 | P1 | P2 |
|---|---|---|
| 左右移动 | A / D | ← / → |
| 跳跃 | W（按下沿） | ↑（按下沿） |
| 蹲下 | S（持续） | ↓（持续） |
| 轻拳 / 轻脚 | J / K | Numpad1 / Numpad2 |
| 重拳 / 重脚 | L / I | Numpad4 / Numpad5 |
| 必杀辅助 | U | Numpad0 |
| 指令必杀 | 相对方向↓↘→ + J或L | 相对方向↓↘→ + 轻拳或重拳 |
| 防御 | 持续相对对手的后方向 | 同左 |

注意：普通数字行不等于数字小键盘；NumLock/笔记本键盘差异要实测。动作按 keydown edge 触发，长按攻击不会自动连发。前后方向以角色朝向判断指令，防御则相对敌人位置。

菜单 ←/→ 选角色；↑/↓ 在三种模式循环；Enter 开始。ESC 暂停/恢复。F2切换判定框；暂停状态N恰好推进一个逻辑tick。R仅训练有效。

触屏只操作P1；方向/跳跃/四种拳脚/必杀各按钮。建议横屏，桌面键盘最佳。点击帮助/素材说明会暂停；关闭对话框后仍需继续游戏。窗口失焦/切标签自动暂停，不自动恢复。

## 攻防规则

- 初始生命1000，没有角色选择以外的装备/成长系统。
- 非空中、且处于idle/walk/crouch/block，按后可防mid；下后防low，站后防high。空中不能防御；攻击/受击/倒地不能临时防。
- 蹲下时任一普通攻击转为low；空中任一普通攻击转air。空中不能启动special。
- 普通防御无削血；必杀格挡扣9，但不会因削血扣到0（最低1）。
- 单次攻击serial只命中一次，由connected锁定；投射物碰到一次即移除。
- 命中/格挡后，普通攻击可在规定取消窗口接受special；空挥不可取消。建议近身J命中后按U测试。
- 连击判定基于目标仍hit/down；第2击起每击衰减10%，最低50%，四舍五入。comboDamage累加；100 frame后显示清空。
- 必杀无能量门槛；meter虽在状态中累积，但不是当前游戏的消耗系统/UI。不要自行加入能量条导致无法出招。
- 起跳水平初速 input.x×3.7，重力.66；落地立即结束air攻击，避免站地空踢。
- 角色向对方自动转身只在可行动、地面阶段；出招锁朝向，不在出招中随对手穿过突然镜像。

## 回合 / 胜负

- 常规回合clock=3600 tick（60秒，不包含intro/hitstop/ending中扣时）。两胜制，不是固定只能三回合：平局不计胜，可能继续。
- intro持续150 tick；age105播报FIGHT；ending持续165 tick。
- KO或超时比较剩余血量，相同为平局。清投射物，输方倒地/赢方胜利状态。
- 两胜进入result，按钮再战/返回选人；再战分数清零。
- 训练不结束回合：出现血量≤0时双方恢复1000；R会重建角色、清招式/投射物/缓冲/停顿。按R不会切回主菜单。

## 连续试玩脚本

1. 选AVA → TRAINING → Enter，等待FIGHT消失。
2. D前进、A后退，W跳；按J/K/L/I，看四招不同动作。
3. 靠近假人，J后快速U，观察连击数与伤害；远离空挥J后U不会直接取消。
4. S+K蹲攻，跳起K空中攻击，落地动作回到idle。
5. ESC → F2 → N逐帧，观察启动阶段无红框、有效阶段有红框；R重置。
6. 回菜单选REN，U会发出远程气劲；不能把它做成AVA同款冲刺。
7. VERSUS测试P2移动/重拳；两边同时轻拳距离合适会同帧相杀。
8. ARCADE等待CPU靠近攻击；测试后方向和下后防御。
9. 打满两胜看result，点击再战确认wins归零。
10. 帮助、静音、全屏、触控、切标签暂停分别实测。

## 不在目标内

无联网/回滚、排位、手柄、投技、3v3、小跳大跳、翻滚、关卡选择、同角色对战、移动端P2、存档/经济系统。不要在复现时自行加上。
