# 02｜画面与界面规格

以下坐标均为 **960×540 逻辑坐标**。精确 CSS 见冻结项目 `src/ui/styles.css`；背景/粒子具体绘制顺序见 `src/rendering/Renderer.ts`。文档中的列表不是用来代替精确源文件的。

## 视口 / DPI

- `html/body/#app` 占满窗口，overflow hidden；body 背景 `#020306`。16:9 画面居中，剩余空间黑边，不拉伸、不裁切。
- `.stage-sizing` 尺寸：`width=min(innerWidth,(innerHeight-reserve)*960/540)`；height = width×540/960。
- coarse pointer 或窗口宽≤700 时，reserve=86，为触控条留空间；否则 reserve=0。
- `#viewport` 固定 960×540，transform-origin 左上，CSS scale=width/960。
- Pixi 实际 resolution = clamp(显示宽/960×DPR, 0.1, 4)，最终 canvas backing store 与显示像素匹配。CSS width/height 仍为 960/540（`!important`），避免 autoDensity 与 CSS 缩放叠加。
- 1440×900、DPR1：画面 1440×810，顶/底各45黑边；画布1440×810。
- 1280×800、DPR2：画面1280×720，顶/底各40；画布2560×1440。
- 无整屏 CRT 扫描线或 blur，避免重新损伤人物细节。

## 主色 / 字体

- 金色 `#ffce55`，赤燕红 `#ff5059`，玄武蓝 `#70bcff`，奶白 `#fff2cf`，深蓝黑底。
- 标题优先系统 Impact / Arial Narrow，正文 Arial Black / PingFang SC / Microsoft YaHei，信息标签 monospace。没有远程字体。
- 标题是原生文本 + 描边/层叠硬阴影，不是现成 KOF logo；不要替换成其它字标。
- **跨平台字体限制**：系统未安装 Impact 时会 fallback，字宽/轮廓可能有差别。字体不打包，因为没有获得其再分发许可。近像素对比要在同系统/同字体/同浏览器做；不私自下载不明字体。

1. 960×540 渐变 sky canvas：顶部 `#111326`，44% `#4a263a`，底 `#0b2027`。
2. skyline.png 重复5次，scale2.8，x=i×268−20，y=−12，alpha .65。
3. street.png scale2，位置(−230,135)。
4. 从 road.png 切(48,288,112,78)，scale2，重复5块，位置(i×224−60,452)，alpha .92。
5. props.png scale2，位置(−230,135)，alpha .9。
6. car.png scale1.4，(70,353)；hydrant.png scale1.8，(794,354)。

## 移动布局

保持完整横向世界，竖屏会有较大黑边，这是目标行为，不要靠裁掉对手解决。触控条86px，方向按键深蓝矩形，攻击按键红色圆形，必杀金色。390px和320px宽均不能横向溢出；多指输入依赖 pointer capture。

## 动态感与清晰度

- 原生图集、固定锚点、按战斗阶段重定时是清晰流畅的基础；不是插入随机补帧。
- Hitstop 命中停顿、轻重命中震屏、短暂白闪、径向火花、格挡弧形、落地尘、必杀环和波动尾迹要保留。
- 战斗不随渲染帧率变快；30/60/144Hz都60Hz模拟。这里没有宣称实现逐像素碰撞、回滚或物理插帧。
